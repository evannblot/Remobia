# Remobia

Site de présentation de Remobia à Laval, adapté pour GitHub Pages à partir du site existant.

La présentation, le catalogue et le formulaire de préparation de devis sont conservés. Cette version statique ne peut pas exécuter les services serveur du site d’origine : les demandes sont préparées dans le navigateur, puis copiées ou téléchargées, sans envoi automatique.

Les fichiers du site et les instructions de modification seront ajoutés dans le prochain commit. La publication GitHub Pages sera annoncée après vérification.
